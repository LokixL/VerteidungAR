Indoor Fire Detection using Acoustic Detection
FieldContent
Use Case NumberUC-1
ReferencesUser Analysis; User Requirements
Short DescriptionThe system detects fire in indoor environments and provides information about fire type, intensity, and possible source direction using acoustic information.
ActorsFirefighter
TriggerThe firefighter uses the device in a smoke-filled, visibility-limited, or otherwise difficult-to-assess indoor environment.
Preconditions

Postconditions

THE BRIDGE

From the user to the developer

Der Use Case übersetzt die Erkenntnisse der User Analysis in eine konkrete Interaktion zwischen Feuerwehrkraft und System. Daraus lassen sich anschließend User Stories und technische Anforderungen ableiten.

USERFirefighter in a difficult-to-assess environment
INTERACTIONDevice-assisted indoor situation assessment
DEVELOPMENTRequirements for functionality, usability and reliability
Kurzer Sprechtext · ca. 20–30 Sekunden

„Die User Analysis beschreibt, unter welchen Bedingungen Feuerwehrkräfte arbeiten. Um daraus konkrete Anforderungen abzuleiten, habe ich Use Cases formuliert. Als Beispiel zeigt Tabelle 8 die Indoor Fire Detection: Eine Feuerwehrkraft soll in einer schwer einzuschätzenden Umgebung zusätzliche akustische Informationen erhalten. Der Use Case beschreibt das angestrebte Verhalten des Systems. Daraus werden im nächsten Schritt die User Stories und technischen Anforderungen abgeleitet.“

Important distinction: UC-1 beschreibt den vorgesehenen Einsatz des zukünftigen Systems. Eine zuverlässige automatische Branderkennung, Brandtypklassifikation und Richtungsschätzung sind mit dem Forschungsprototyp noch nicht validiert.
